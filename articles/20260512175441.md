## 1. 要塞の心臓部：Mac Studio (M4 Ultra)

私が試した中で、Qwen2.5 32Bモデルをフルスピードで動かしながら、同時にObsidianとブラウザを開き続けられるのは、Apple SiliconのUltaチップだけでした。CPUとGPUが統一メモリを共有する「UMA（Unified Memory Architecture）」は、AIのメモリ集約的なワークロードに対して、他のどんなPCよりも圧倒的に効率的です。

**私の選択**: M4 Ultra / 192GB統合メモリ / 2TB SSD
